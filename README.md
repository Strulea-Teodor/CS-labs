Laboratory works for the Cryptography & Security course, FAF-242, Technical University of Moldova.

Each laboratory work lives on its own branch and in its own folder:

| Lab | Branch | Folder | Topic |
|---|---|---|---|
| 1 | `Lab-1` | `Lab1/` | Caesar cipher over the Romanian alphabet (one key / two keys) |
